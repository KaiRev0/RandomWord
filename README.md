
Случайное слово

Реализуйте сайт, выводящий случайные слова. Продумайте структуру базы данных для хранения слов (слово, часть речи). Вручную вбейте в базу 50-100 слов для разных частей речи (существительные, прилагательные, глаголы, наречия). Все данные должны храниться в базе данных и выдаваться по запросу. Скачать верстку для проекта.
Основные возможности проекта

    Кнопка для генерации случайного слова.
    Вывод случайного слова.

Главная страница

На главной странице сайта должна быть кнопка "Показать случайное слово". При нажатии на кнопку сайт выбирает случайное слово из базы данных и выводит его на странице.
Результат

После нажатия на кнопку сайт должен вывести:

    Случайное слово.
    Часть речи слова.

Дополнительные возможности

    Кнопка "Еще" для показа другого случайного слова.
    Вывод количества букв в слове.
    Вывод ударения в слове.
